# Funktionen Admins

Funktionen, die primär für Admin-Prozesse gedacht sind - z. B. für den Aufnahmeprozess neuer Mitglieder. Diese werden meist als einzelne Schritte in Slacks Workflow Builder eingesetzt, statt als eigenständige, direkt nutzbare Funktion.
